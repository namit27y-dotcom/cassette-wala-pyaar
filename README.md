# 📼 Cassette Wala Pyaar ❤️

**Gaane Purane, Feelings Naye.**

Cassette Wala Pyaar is a nostalgic Retro Bollywood music website inspired by vintage audio cassettes, 90s Bollywood romance, classic melodies, and the golden era of Indian cinema.

## ✨ Features

- 📻 Nostalgic Retro Bollywood UI
- 🎵 Interactive music player
- 💿 Featured Bollywood mixtapes
- ❤️ Vintage cassette artwork and romantic aesthetics
- 🎬 90s Bollywood-inspired visuals
- 🎨 Cinematic animations and warm colors
- 📱 Responsive design for desktop and mobile

## 🎤 Featured Artists

- Salman Khan — 90s Bollywood nostalgia
- Kumar Sanu
- Kishore Kumar
- S. P. Balasubrahmanyam
- Ankit Tiwari
- Arijit Singh

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript / TypeScript
- Vite
- React (if used in the current implementation)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/namit27y-dotcom/cassette-wala-pyaar.git
cd cassette-wala-pyaar
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🎨 Design

The website combines deep burgundy colors, golden highlights, vintage cassette covers, handwritten love notes, and nostalgic Bollywood-inspired visuals to create an immersive music experience.
